# Day 20 - Customer Segmentation Using Predicted LTV

## Objective

Identify high-value customers using predicted Customer Lifetime Value.

## Method

1. Loaded the trained LTV model.
2. Predicted LTV for every customer.
3. Divided customers into four segments using quartiles.

## Customer Segments

- Low Value
- Medium Value
- High Value
- Premium Value

## Business Applications

Premium Value Customers

- Loyalty rewards
- Personalized offers
- Dedicated customer support

High Value Customers

- Upselling
- Cross-selling

Medium Value Customers

- Promotional campaigns

Low Value Customers

- Engagement campaigns
- Retention offers
