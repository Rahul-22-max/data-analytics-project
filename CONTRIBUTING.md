# Contributing Guidelines

Thank you for your interest in contributing to this project.

## Project Setup

1. Clone the repository.

```bash
git clone https://github.com/Rahul-22-max/data-analytics-project.git
```

2. Navigate to the project directory.

```bash
cd data-analytics-project
```

3. Install the required dependencies.

```bash
py -m pip install -r requirements.txt
```

4. Run the Flask API.

```bash
py api/app.py
```

---

## Coding Guidelines

- Follow Python coding standards.
- Write clean and readable code.
- Keep functions simple and modular.
- Add comments where necessary.
- Maintain consistent formatting.

---

## Git Workflow

1. Create a new branch.
2. Make your changes.
3. Commit with a meaningful message.
4. Push your branch.
5. Create a Pull Request.

---

## Reporting Issues

If you find a bug or have a suggestion:

- Open a GitHub Issue.
- Clearly describe the problem.
- Include steps to reproduce it if applicable.

---

## Pull Requests

Before submitting a Pull Request:

- Ensure the project runs successfully.
- Verify that all files are properly documented.
- Update documentation if necessary.
