# Release Notes

# Version 1.0

Release Date: July 2026

## Overview

This is the first stable release of the Customer Churn Prediction & Customer Lifetime Value (LTV) Engine.

The project provides an end-to-end machine learning solution for predicting customer churn using the Telco Customer Churn dataset.
