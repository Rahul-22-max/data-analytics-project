# Known Issues

## Current Limitations

### 1. Limited Dataset

The project uses the Telco Customer Churn Dataset with 7043 customer records.
A larger dataset may improve model performance.

---

### 2. Customer Lifetime Value (LTV)

The current version focuses only on churn prediction.

LTV prediction is planned for a future release.

---

### 3. Dashboard

An interactive dashboard has not yet been implemented.

Future versions may include Power BI, Tableau, or Streamlit dashboards.

---

### 4. Cloud Deployment

The application currently runs locally using the Flask development server.

Cloud deployment is planned for future versions.

---

### 5. Authentication

The REST API does not currently include authentication or authorization.

Future versions may implement JWT authentication.

---

### 6. Monitoring

The project does not include logging or performance monitoring.

Future releases may integrate monitoring tools.

---

## Future Improvements
